## SOBRE O PROJETO

Hotsite desenvolvido para **orientar e facilitar o acesso de candidatos às oportunidades de emprego e estágio da Nexa** durante eventos de empregabilidade.

O projeto foi desenvolvido em colaboração com **Larissa Nunes**, com o objetivo de reduzir barreiras no processo de candidatura, especialmente para o público operacional, oferecendo uma experiência simples, didática e acessível.

A página reúne informações sobre a empresa, direciona os candidatos para as oportunidades disponíveis na **Gupy** e apresenta um passo a passo para auxiliar no processo de inscrição.

🌐 [Acesse o site](https://portalnexa.vercel.app/)

## FUNCIONALIDADES

* **Apresentação da empresa** — informações sobre a Nexa e suas oportunidades
* **Acesso às vagas** — direcionamento direto para o portal de candidaturas da Gupy
* **Passo a passo** — guia didático com instruções para realização da candidatura
* **FAQ** — respostas para dúvidas frequentes dos candidatos
* **Tema claro/escuro** — alternância de tema conforme a preferência do usuário
* **Layout responsivo** — interface adaptada para diferentes dispositivos

<h2 id="projeto">PROJETO</h2>

Projeto voluntário desenvolvido para orientar e facilitar o acesso de candidatos às oportunidades de emprego e estágio da Nexa pelo portal da Gupy. O objetivo foi reduzir barreiras no processo de candidatura — especialmente para o público operacional — entregando um guia simples, didático e acessível sobre a empresa, as vagas e o passo a passo de inscrição.

🌐 [Acesse o site](https://portalnexa.vercel.app/)

<h2 id="funcionalidades">FUNCIONALIDADES</h2>

- **Apresentação da Nexa** — explicação clara sobre a empresa e suas oportunidades
- **Link direto para o portal** — acesso imediato às vagas via Gupy
- **Passo a passo** — seções expansíveis com guia didático de candidatura
- **FAQ** — respostas para as dúvidas mais frequentes dos candidatos
- **Tema claro/escuro** — alternância via toggle button conforme preferência do usuário
- **Layout responsivo** — interface adaptada para todos os dispositivos
